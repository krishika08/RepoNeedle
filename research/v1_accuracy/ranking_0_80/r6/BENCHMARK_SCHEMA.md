## 1. Benchmark Architecture

The Phase R6 Independent Benchmark evaluates code retrieval quality under realistic developer information constraints. The data model comprises three decoupled layers:
1. **Query Specification**: The developer's request (issue description, PR summary, navigation prompt).
2. **Candidate Pool Specification**: A pre-retrieved candidate pool of files ($50 \le N \le 600$) generated by RepoNeedle's multi-channel M1 retriever.
3. **Quarantined Evaluation Oracle**: Ground truth target files accessible strictly by the offline scoring harness.

## 3. Strict Permitted vs Quarantined Features

| Field Name | Runtime Ranker Permitted | Offline Evaluator Only | Reason / Leakage Risk |
| :--- | :---: | :---: | :--- |
| `query_id` | YES | YES | Non-informative identifier |
| `repo` | YES | YES | Allows repository-level graph caching |
| `query_text` | YES | YES | Primary retrieval input |
| `seed_files` | YES | YES | Observable user-supplied context (e.g. PR diff header) |
| `cand.path` | YES | YES | Search target identity |
| `cand.scores` | YES | YES | First-stage BM25 / lexical scores |
| `cand.ast_symbols` | YES | YES | Static AST syntax observable from source code |
| `cand.imports` | YES | YES | Static import declarations observable from source |
| `_evaluator_gold.gold_files` | **NO** | YES | **Oracle Target Label** (Inference Violation) |
| `_evaluator_gold.gold_roles` | **NO** | YES | **Target Subtype Label** (Inference Violation) |
| `task_type` | **NO** | YES | Replaced by unsupervised query intent detector |

## 4. Evaluation Metric Formats

For an evaluation pool of $Q$ queries where query $q$ has ground-truth files $G_q$ and ranked candidate list $R_q = [c_1, c_2, \dots]$:

1. **Mean Reciprocal Rank (MRR)**:
   $$\text{MRR} = \frac{1}{Q} \sum_{q=1}^Q \frac{1}{\min_{g \in G_q} \text{rank}(g, R_q)}$$
   *(If no $g \in G_q$ appears in $R_q$, $\text{ReciprocalRank} = 0$).*

2. **Hit@1**:
   $$\text{Hit@1} = \frac{1}{Q} \sum_{q=1}^Q \mathbb{I}(\text{rank}_{\min}(G_q, R_q) == 1)$$

3. **Recall@$K$ ($K \in \{5, 10, 20\}$)**:
   $$\text{Recall@}K = \frac{1}{Q} \sum_{q=1}^Q \frac{|G_q \cap R_q[:K]|}{|G_q|}$$

4. **Multi-Target Complete Coverage**:
   $$\text{CompleteCoverage} = \frac{1}{Q} \sum_{q=1}^Q \mathbb{I}(G_q \subseteq R_q[:20])$$
