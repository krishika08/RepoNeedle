# RepoNeedle V1.1.0 Release Notes: Change-Impact Retrieval Engine

**Release Version**: `1.1.0`  
**Release Date**: November 2026  
**Integration Branch**: `v1.1-change-impact`  
**Compatibility**: 100% backwards-compatible with V1.0.0  

---

## 1. Release Highlights

RepoNeedle V1.1.0 introduces the **Change-Impact Ranking Engine**, an opt-in retrieval architecture engineered for software maintenance, bug fixing, and refactoring queries. 

By propagating relevance across a typed code dependency graph (incorporating static imports, symbol definitions, call sites, and directory proximity), the engine surfaces structurally coupled files that lexical and semantic search miss.

### Key Capabilities:
- **Statistically Verified Relevance Gain**: Delivers $+0.0289$ MRR improvement ($p = 0.0078$) across an independent cohort of 18 unseen open-source repositories.
- **Strict Default Preservation**: The default ranking engine remains `legacy` (V1.0 behavior). Existing integrations experience zero behavior drift.
- **Fail-Safe Fallback**: If graph traversal encounters an unexpected exception, the engine automatically falls back to base lexical/semantic scoring without failing queries.
- **CUD-Pack Invariant Compliance**: Guaranteed zero-token-overflow context window packing across all LLM token budgets.
- **Explainability**: Every scored candidate provides structured attribution tracing which seed files and dependency edges contributed to its score.
- **Interactive Performance**: True end-to-end retrieval latency of **64.51 ms** (P50: 64.22 ms, P95: 67.32 ms) and peak RAM of **18.51 MB** on standard CPU hardware.

## 2. Quickstart & Usage Guide

### 2.1 Python API Usage

#### Standard Opt-In (Minimal):
```python
from reponeedle import RepoNeedleEngine

# Initialize engine with Change-Impact ranker
engine = RepoNeedleEngine(
    repo_path="/path/to/my-repo",
    ranking_engine="change_impact"
)

# Execute query with deterministic CUD-Pack packing
result = engine.query(
    query="modify session store in auth/session.py to support redis clustering",
    token_budget=8000
)

# Inspect packed files
for item in result.packed_files:
    print(f"[{item.score:.3f}] {item.file_path}")
    if item.explanation:
        print(f"       Explanation: {item.explanation}")
```

#### Query-Level Override:
```python
# Leave default engine as legacy
engine = RepoNeedleEngine(repo_path="/path/to/my-repo")

# Opt in dynamically for change-aware queries
result = engine.query(
    query="refactor database connection pool",
    ranking_engine="change_impact"
)
```

#### Advanced Tuning with `ChangeImpactConfig`:
```python
from reponeedle import RepoNeedleEngine, ChangeImpactConfig

custom_config = ChangeImpactConfig(
    enable_graph=True,          # Enable dependency graph propagation
    max_hops=2,                 # Graph exploration depth (1 or 2)
    decay_factor=0.6,           # Attenuation factor per hop
    confirmed_weight=1.0,       # Weight for verified imports & definitions
    heuristic_weight=0.35,      # Weight for directory proximity
    fallback_on_error=True,     # Fall back to base scoring on exception
    return_explanations=True    # Attach explanations to ScoredFile
)

engine = RepoNeedleEngine(
    repo_path="/path/to/my-repo",
    ranking_engine="change_impact",
    change_impact_config=custom_config
)
```

### 2.2 CLI Usage

The RepoNeedle CLI provides first-class support for the Change-Impact engine:

```bash
# Standard query using Change-Impact ranking
reponeedle search "refactor payment gateway in billing/stripe.py" \
    --ranking-engine change_impact \
    --budget 8000

# Explain ranking decisions in CLI output
reponeedle search "fix token expiration in auth/jwt.py" \
    --ranking-engine change_impact \
    --explain

# Customize traversal depth and decay
reponeedle search "update user schema" \
    --ranking-engine change_impact \
    --graph-depth 1 \
    --decay-factor 0.5
```

## 3. Migration and Compatibility

| Interface / Component | V1.0 Behavior | V1.1 Behavior (Default) | V1.1 Behavior (Opt-In) |
| :--- | :--- | :--- | :--- |
| `RepoNeedleEngine()` default ranker | `"legacy"` | `"legacy"` (Unchanged) | `"change_impact"` |
| Token Budget Packing | CUD-Pack zero overflow | CUD-Pack zero overflow | CUD-Pack zero overflow |
| CLI default ranker | `"legacy"` | `"legacy"` (Unchanged) | `--ranking-engine change_impact` |
| `ScoredFile.explanation` | `None` | `None` | Structured string explanation |
| Error handling | Standard exceptions | Standard exceptions | Automatic fallback (configurable) |

### Reverting / Rollback
If you observe unexpected candidate ordering on specific legacy queries, simply omit the `ranking_engine` parameter or specify `ranking_engine="legacy"`.

## 5. Known Limitations & Research Context

1. **Aspirational Target (0.80+ MRR)**: The long-term target of 0.80+ MRR remains an aspirational research goal. V1.1 achieves 0.3235 validation MRR and 0.3183 held-out MRR on the historical R5 ARB benchmark, and achieves 0.6708 validation MRR (vs 0.6472 baseline, +0.0236) and 0.5467 held-out MRR (vs 0.5215 baseline, +0.0252) on the 18-repository R6 independent benchmark (0.6282 vs 0.5994 pooled, +0.0288).
2. **Sub-Cohort Power**: While the pooled 18-repository cohort demonstrates statistically significant generalization ($p = 0.0078$), the 5-repository held-out subset in isolation ($N=50$) is underpowered ($p = 0.5025$). For this reason, Change-Impact is released as an opt-in capability rather than overriding the default ranker.
3. **Language Support**: AST symbol and dependency extraction is optimized for Python, TypeScript/JavaScript, Go, Rust, Java, and C/C++. Unrecognized file types fall back to directory proximity and lexical matching.
